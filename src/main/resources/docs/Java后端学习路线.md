# Java 后端学习路线

## 使用说明

- 适用对象：零基础或转行，目标是 Java 后端开发岗位
- 时间预期：每天 2-3 小时，6-9 个月达到可面试水平
- 核心原则：每个阶段都要有可运行的产出，不要只看视频

## 阶段一：开发环境与工具（1-2 周）

目标：能独立创建、运行、调试一个 Java 项目。

核心知识点：

- JDK 安装与环境变量，理解 java、javac 命令的作用
- IDEA 基本使用：断点调试、重构、Maven 面板
- Git：add、commit、branch、merge、remote
- Maven：pom.xml、依赖坐标、生命周期、依赖冲突排查

练习：用 Maven 创建一个命令行程序，提交到 GitHub。

常见误区：花一周折腾编辑器主题和插件，实际代码没写几行。

## 阶段二：Java 语言核心（4-6 周）

目标：写出结构清晰、能正确处理异常的面向对象代码。

核心知识点：

- 语法：变量、流程控制、数组
- 面向对象：封装、继承、多态、接口、抽象类
- 集合：ArrayList、HashMap、HashSet 的底层结构与使用场景
- 异常：checked 与 unchecked 的区别，try-with-resources
- 泛型、反射、注解，先会用，原理可以放到后面
- IO 与 NIO 基础

练习：实现一个学生成绩管理 CLI；手写一个简易 LRU 缓存。

常见误区：只背语法不看源码；过早钻研 JVM 调优。

## 阶段三：并发与 JVM 入门（3-4 周）

目标：理解线程安全，能解释常见的并发问题。

核心知识点：

- 线程生命周期、synchronized、volatile
- 线程池：核心参数、拒绝策略、为什么不用 Executors 默认工厂
- 并发容器：ConcurrentHashMap、CopyOnWriteArrayList
- Java 内存模型与 happens-before，能讲清可见性
- JVM 内存结构、类加载过程、垃圾回收基础

练习：用线程池实现批量任务处理器；用 jstack 分析一次死锁。

常见误区：只背八股，不写并发代码。

## 阶段四：Web 与框架（4-6 周）

目标：独立开发 REST 接口并连接数据库。

核心知识点：

- HTTP：请求方法、状态码、Header、Cookie 与 Session
- Spring Boot：IoC、AOP、自动配置、MVC
- MyBatis 或 MyBatis-Plus：映射、动态 SQL、分页
- 参数校验、全局异常处理、统一返回结构
- 接口文档：Knife4j 或 Swagger

练习：做一个待办事项 API，包含增删改查、分页和参数校验。

常见误区：只会复制注解，不理解 Bean 的生命周期。

## 阶段五：数据库与中间件（4-6 周）

目标：能设计表、写高效 SQL、正确使用缓存。

核心知识点：

- MySQL：索引原理（B+ 树、最左前缀）、事务隔离级别、锁、explain
- Redis：五种数据结构、过期策略、缓存穿透、击穿、雪崩
- 消息队列：异步、削峰、幂等，了解 RabbitMQ 或 Kafka
- 缓存一致性：先更新数据库还是先删缓存

练习：给待办 API 加 Redis 缓存；用 explain 优化一条慢查询。

常见误区：一上来就分库分表；缓存不设置过期时间。

## 阶段六：项目与面试（4-6 周）

目标：有一个能讲 15 分钟的项目，能通过初级后端面试。

核心知识点：

- 项目分层：controller、service、mapper，DTO 与 VO 转换
- 日志、配置管理、单元测试、部署
- 简历项目描述与面试讲述
- 算法：数组、链表、哈希、二叉树、简单动态规划

练习：把前面的 API 扩展成完整项目，部署到云服务器。

常见误区：项目只做 CRUD；简历上写“精通”。

## 学习资源选择原则

- 官方文档优先，视频作为辅助
- 视频只看一套，避免反复从入门开始
- 每学一个知识点，写一个最小可运行示例
- 遇到问题先看异常栈和日志，再搜索
